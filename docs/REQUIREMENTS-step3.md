# 3단계 요구사항 명세서

| 요구사항 | 사용자 행동 | 추가 설명 | 예외 |
| --- | --- | --- | --- |
| 사용자는 주문 확인 페이지로 이동할 수 있다. | 장바구니 페이지에서 '주문 확인' 버튼 클릭 | 주문한 상품에 대해 최대 조합, 최소 사용 개수로 쿠폰을 사용한다.| 요청 실패 시 에러 알림을 띄우고 페이지를 이동하지 않는다. |
| 사용자는 보유한 쿠폰 목록을 확인할 수 있다. | 주문 확인 페이지에서 '쿠폰 적용' 버튼 클릭 | 쿠폰 목록을 불러온다. 쿠폰이 유효하면 선택할 수 있고, 쿠폰이 유효하지 않으면 비활성화된다. |  |
| 사용자는 유효한 쿠폰을 선택할 수 있다. | 쿠폰 목록 모달에서 각 쿠폰의 체크박스 클릭 | 쿠폰을 선택할 때마다 적용될 할인 금액을 계산한다. | 요청 실패 시 에러 알림 띄우고 선택 상태와 할인 금액을 롤백한다. |
| 사용자는 유효한 쿠폰을 적용할 수 있다. | '사용하기' 버튼 클릭 | DB에 현재 선택된 쿠폰을 등록하기 전에 먼저 그 쿠폰들이 유효한지 검사한다. | 유효하지 않을 시 에러 알림을 띄우고 쿠폰 목록을 다시 불러온다. <br><br>모달을 닫는다면, 변경사항을 되돌리고 이전에 적용된 쿠폰 상태를 유지한다. |
| 사용자는 배송 정보를 변경할 수 있다. | '제주도 및 도서 산간 지역' 체크박스 클릭 | 선택한 배송 정보에 따라 배송비, 쿠폰 할인 금액을 계산한다. | 요청 실패 시 에러 알림 띄우고 배송 정보를 롤백한다. |
| 주문 예정인 상품들을 기준으로 주문 금액, 쿠폰 할인 금액, 배송비, 총 결제 금액을 확인할 수 있다. | 쿠폰 적용 또는 배송 정보 변경 시 |  |  |
